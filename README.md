## 📚 Conteúdos Estudados

Durante as aulas são abordados temas como:

- Introdução ao **Delphi**
- Estrutura de um projeto Delphi
- Programação em **Object Pascal**
- Utilização de **componentes visuais**
- Criação de **interfaces gráficas (GUI)**
- Manipulação de **eventos**
- Trabalhando com **formulários**
- Entrada e saída de dados
- Desenvolvimento de **pequenos sistemas**

## 🧰 Tecnologias Utilizadas

- **Delphi**
